# Malthe Munkøe — personal website

A small static site migrated from the original Wix site. The HTML/CSS can be hosted directly with GitHub Pages; there is no build step.

## Files

- `index.html` — home / index
- `about.html` — about
- `research.html` — academic publications
- `portfolio.html` — applied works
- `writing.html` — writing
- `teaching.html` — teaching
- `style.css` — site styles

## GitHub Pages setup

1. Create a GitHub repository and upload all of the files above to the **repository root** (not inside another folder).
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the folder **`/(root)`**, then click **Save**.
5. GitHub will publish the site and provide the Pages URL.

No framework, package manager, or compilation step is required. Subsequent content or styling changes can be made by editing the corresponding HTML/CSS file in the repository.
